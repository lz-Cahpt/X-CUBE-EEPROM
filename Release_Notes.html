Release Notes for

X-CUBE-EEPROM Package

Copyright © 2025 STMicroelectronics

Purpose

The X-CUBE-EEPROM package is associated to the AN4894 How to use EEPROM emulation on STM32 MCUs which aims at providing firmware examples to substitute a standalone EEPROM by emulating the EEPROM mechanism using the on-chip Flash devices. For the STM32WB Series a special example is provided to emulate an EEPROM alongside the Heart Rate BLE application. For the STM32H5 Series a special example is provided to emulate the EEPROM mechanism in the high cycle data area.

Here is the list of references to user documents:

  • DM00311483
    AN4894 How to use EEPROM emulation on STM32 MCUs
